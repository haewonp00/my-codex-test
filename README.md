# YOLO 분리수거 AI 오류 분석

YOLO11n으로 plastic(0), paper(1), metal(2)을 탐지하는 프로젝트입니다. 높은 confidence가 정답을 보장하지 않는 실제 실패 사례를 분석하고, 실험 조건과 데이터 변경 이력을 기록합니다.

| 자료 | 내용 |
|---|---|
| [정리본](정리본/) | 초기 학습·추가 데이터·label_fix_v1 학습 이력과 정리한 노트북 |
| [라벨 수정안 v2](수정안_v2/) | 직접 확인한 두 이미지의 라벨 수정안, 검증·평가 코드 |
| [배경 오탐 실험 v1](배경오탐_실험_v1/) | 사용자 촬영 빈 배경 55장 검토 기록, 데이터 준비·기존 모델 평가 코드와 결과 |
| [준비된 데이터셋](배경오탐_실험_v1/데이터셋/) | train 766장, val 90장, test 90장; 별도 빈 배경 평가 16장·화질 보류 4장 |

## 확인한 결과와 한계

기존 label_fix_v1 best.pt는 confidence 0.25, imgsz 640, IoU 0.7에서 빈 배경 평가 후보 16장 중 13장을 paper로 오탐했습니다(사진 기준 81.25%). 이 수치는 이번 개발용 16장의 결과이며 실제 환경 전체의 오탐률을 뜻하지 않습니다. 실제 장소 독립성은 아직 확인되지 않았습니다.

이번 작업에서는 재학습하지 않았고 개선 후 성능 수치는 없습니다. 배경 추가 효과를 구분하려고 기존 label_fix_v1 데이터에 배경 35장만 추가했으며, 라벨 수정안 v2는 별도 실험으로 유지했습니다. 기존 val/test와 모델 원본은 보존했습니다. best.pt는 저장소에 포함하지 않았으므로 실제 가중치를 별도로 준비해야 합니다.

코드 실행은 각 폴더 README와 노트북을 참고하세요. 원본 `분리수거_ai__첫_학습.ipynb`는 그대로 보존했습니다. 데이터 출처와 검토한 라벨 변경 근거는 [수정안 v2 README](수정안_v2/README.md)에 기록했습니다.
