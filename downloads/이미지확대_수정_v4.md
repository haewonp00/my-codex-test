# 안내 이미지 확대 터치 수정 v4

이 패치는 v3 이미지 업데이트를 설치했고 Flutter analyze가 통과했지만 23개 중 확대 테스트 1개가 실패한 사용자용입니다. 이미지 v3를 먼저 적용한 상태가 기준입니다.

## 확인한 로그

- flutter pub get 성공
- flutter analyze: No issues found
- flutter test: 22개 통과, 확대 테스트 1개 실패
- guide-open-image가 찾아졌으나 중심 좌표에 터치가 전달되지 않아 guide-image-dialog가 열리지 않음

## 수정

이미지 디코딩 중에도 1:1 영역을 유지하는 AspectRatio를 추가했습니다. 제공 이미지 4장이 모두 1080×1080인 점을 반영합니다. GestureDetector의 opaque 터치 영역을 사용해 이미지의 빈 영역에서도 터치를 받게 합니다. 이미지 파일은 변경하지 않습니다. 확대 창도 로딩 전부터 전체 표시 영역을 확보합니다.

테스트는 터치 대상의 폭·높이가 양수이고 1:1인지, 실제 중앙이 hitTestable인지 확인한 다음 정상 tap으로 대화상자를 열도록 했습니다. warnIfMissed:false로 경고를 숨기거나 콜백을 직접 호출해 검증을 건너뛰지 않습니다.

## 적용

1. GitHub downloads/recycling_guide_zoom_fix_v4.zip → Download raw file(↓) 또는 View raw로 다운로드.
2. 모두 압축 풀기. 예시 폴더 C:\Users\haewo\Downloads\recycling_guide_zoom_fix_v4.
3. 실행 중인 flutter run만 종료. 서버는 유지해도 됩니다.

```powershell
$patch = "C:\Users\haewo\Downloads\recycling_guide_zoom_fix_v4"
Test-Path "$patch\Apply-GuideZoomFix.ps1"
```

True이면:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\Apply-GuideZoomFix.ps1" -PatchRoot $patch -AppRoot "C:\Users\haewo\recycling_app"
```

기존 파일을 recycling_guide_zoom_backup_날짜시간에 백업하고 아래 두 파일만 교체합니다.

- lib/ui/guide_page.dart
- test/widget_test.dart

이미지 4장, 안내 데이터, pubspec.yaml, 서버, 모델, Android 설정은 변경하지 않습니다.

```powershell
cd C:\Users\haewo\recycling_app
dart format lib test
flutter analyze
flutter test
```

이번 패치는 새 패키지나 assets 변경이 없어 pub get을 다시 실행할 필요는 없습니다. 통과하면 flutter run으로 앱을 재실행하고 이미지를 눌러 확대/닫기/품목 변경을 확인합니다.

## 검증 범위

Dart/PowerShell 구문과 패치 ZIP을 검사했습니다. 이 환경에는 Flutter SDK/Windows/휴대폰이 없어 수정 후 실제 flutter analyze/test 및 S25 동작은 실행하지 못했습니다. 23개 테스트가 모두 통과했다고 주장하지 않습니다. 실제 실행 결과를 확인해야 합니다.
