# S25 카메라 촬영·사진 분석 실행 v6

현재 앱에는 카메라 촬영, 갤러리 선택, 서버 업로드와 박스 표시가 이미 있습니다. 이번 파일은 소스/모델을 교체하는 패치가 아니라 **기존 서버 시작 + USB 포트 연결 + 휴대폰 앱 설치/실행**을 묶은 Windows 도구입니다.

현재 구조: S25 촬영 사진 → USB(adb reverse) → PC FastAPI → best.pt 분석 → 휴대폰 결과 표시.

지원 모델은 plastic(0), paper(1), metal(2)입니다. 비닐·복합재질은 사진 자동 분석 대상이 아니며 직접 선택한 안내만 제공합니다. 휴대폰 단독 오프라인 추론, 실시간 영상 추론, 새 YOLO 클래스 추가/재학습은 이번 작업에 포함하지 않습니다.

## 1. 다운로드와 준비

https://github.com/haewonp00/my-codex-test/blob/main/downloads/recycling_phone_analysis_v6.zip

파일 화면의 Download raw file(↓) 또는 View raw로 받고 모두 압축 풀기 합니다.

```text
C:\Users\haewo\Downloads\recycling_phone_analysis_v6
├─ Start-PhoneAnalysis.ps1
└─ 처음읽기_실행방법.md
```

- S25를 USB 데이터 케이블로 연결합니다.
- 개발자 옵션의 USB 디버깅을 켜고 휴대폰의 디버깅 허용을 누릅니다.
- 기존 앱/서버 폴더와 서버의 실제 best.pt가 있어야 합니다.
- 기존 flutter run이 있다면 그 터미널에서 종료합니다. 이미 정상 실행 중인 Python 서버는 그대로 사용할 수 있습니다.

## 2. 실행 명령

VS Code PowerShell에서:

```powershell
$tools = "C:\Users\haewo\Downloads\recycling_phone_analysis_v6"
Test-Path "$tools\Start-PhoneAnalysis.ps1"
```

True이면:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$tools\Start-PhoneAnalysis.ps1" -AppRoot "C:\Users\haewo\recycling_app" -ServerRoot "C:\Users\haewo\recycling_server"
```

4단계로 진행합니다.

1. 승인된 휴대폰(device) 확인. 없으면 USB/허용 안내 후 중단합니다.
2. 기존 서버가 정상 응답하면 재사용합니다. 없으면 서버 폴더의 .venv/venv 또는 현재 python을 찾아 새 창에서 uvicorn을 시작하고 /health를 기다립니다.
3. 클래스가 0 plastic, 1 paper, 2 metal인지 확인하고 adb reverse tcp:8000 tcp:8000을 적용합니다.
4. 해당 휴대폰을 지정해 flutter run으로 현재 소스를 설치하고 실행합니다.

이 도구는 파일·모델·기기 권한을 덮어쓰거나 프로세스를 임의로 종료하지 않습니다. 패키지가 없으면 필요한 설치 명령을 출력하고 멈춥니다. 처음 설치한 Python이 아니라 기존 서버용 가상환경을 쓰는 것이 좋습니다.

## 3. Python 환경을 찾지 못하면

기존에 서버가 잘 실행되던 Python 환경을 직접 지정할 수 있습니다. 실제 경로로 바꾸세요.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$tools\Start-PhoneAnalysis.ps1" -PythonExe "C:\Users\haewo\recycling_server\.venv\Scripts\python.exe"
```

위 .venv 경로는 실제 해당 파일이 있을 때만 사용합니다. 다른 환경이면 VS Code의 Python 인터프리터 경로나 기존 서버 터미널에서 아래 명령으로 실행 파일 위치를 확인합니다.

```powershell
python -c "import sys; print(sys.executable)"
```

서버 패키지가 없다면 선택한 Python으로 기존 requirements를 설치한 뒤 다시 실행합니다. 스크립트가 정확한 설치 명령을 출력합니다.

기기가 여러 대면 -DeviceId '실제_adb_기기ID'를 추가하세요. 이 도구는 기본 Android SDK 경로 또는 PATH의 adb를 사용합니다.

## 4. 휴대폰에서 실제로 분석하기

1. 앱의 **사진 촬영**을 누릅니다.
2. 카메라로 물건 전체가 보이게 촬영합니다.
3. 카메라의 완료/확인 버튼을 눌러 앱으로 돌아옵니다.
4. 선택한 사진이 보이면 **분석하기**를 누릅니다. 촬영만으로 분석이 자동 시작되지는 않습니다.
5. 박스 이미지와 물건별 결과 카드가 나오면 종류를 확인합니다.
6. 각 카드에서 세부 품목을 확인하고 배출 안내를 엽니다.

분석에는 USB 연결과 PC 서버가 계속 필요합니다. 직접 안내 찾기·이미지 확대는 설치 후 연결 없이도 됩니다. USB를 다시 꽂거나 PC 서버를 종료했으면 이 실행 도구를 다시 사용하세요.

## 5. 오류를 확인할 위치

- No supported devices connected: S25 USB 연결과 디버깅 허용, adb devices의 device 상태 확인.
- 서버가 시작하지 않음: 새 서버 창의 오류, Python 환경, best.pt 존재 확인.
- 앱은 열리지만 분석 실패: 서버 창 유지, USB 유지, /health 확인.
- 카메라가 열리지 않음: 휴대폰에서 요청하는 카메라 관련 권한 및 Flutter 실행 로그 확인.
- 안내 사진만 나오고 분석은 안 함: 직접 안내 찾기가 아니라 사진 촬영 후 분석하기를 눌렀는지 확인.
- 비닐/복합재질이 다른 클래스로 나옴: 현재 모델이 지원하지 않는 품목입니다. 자동 판정을 확정하지 말고 직접 안내를 사용하세요.

## 검증 범위

현재 Dart 코드에 camera → image_picker → multipart file 업로드 → /predict 경로가 연결되어 있음을 확인했습니다. Python 서버의 API 계약 테스트와 실제 이전 체크포인트 추론 연결은 앞서 검증했지만, 이번 Windows 실행 도구/실제 S25 카메라 실행은 이 Linux 환경에서 수행하지 못했습니다. PowerShell 구문 검사만 수행했습니다. 앱/서버 소스, 모델, 임계값, 학습 데이터는 변경하지 않았습니다.
