# 비닐·복합재질 직접 안내 v5

사용자가 제공한 비닐류.png와 복합 쓰레기.png를 원본 바이트 그대로 앱에 포함합니다. 안내 이미지 v3와 확대 수정 v4를 적용한 앱을 기준으로 하는 추가 패치입니다. 기존 4장도 그대로 남습니다.

## 사용 경로

```text
직접 배출 방법 찾기 → 기타 → 비닐 → 이 품목으로 확인
직접 배출 방법 찾기 → 기타 → 여러 재질이 섞인 포장 → 이 품목으로 확인
```

모델의 클래스는 기존 plastic(0), paper(1), metal(2)뿐입니다. 새 이미지 두 장은 학습 데이터가 아니며, 이 기능이 비닐·복합재질을 사진에서 자동 탐지하는 것은 아닙니다. 직접 품목 선택을 한 경우에만 안내를 표시합니다. 기존 물건 카드에서 사용자가 기타 품목으로 종류를 직접 수정하는 경로도 유지합니다.

기타 품목 선택 화면과 해당 안내에 사진 분석으로 구분하지 않는다는 문구를 표시합니다. 복합 쓰레기 이미지는 내용에 맞춰 '여러 재질이 섞인 포장'에 연결했으며, 모든 복합 폐기물을 이 안내로 판정하지 않습니다. 유리·모르겠어요·가스용기 등 미등록 품목은 준비 중을 유지합니다.

## 2. 파일 교체

실행 중인 flutter run만 종료합니다. Python 서버는 변경하지 않습니다.

```powershell
$patch = "C:\Users\haewo\Downloads\recycling_manual_guides_v5"
Test-Path "$patch\Apply-ManualGuides.ps1"
```

True이면:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\Apply-ManualGuides.ps1" -PatchRoot $patch -AppRoot "C:\Users\haewo\recycling_app"
```

기존 파일을 recycling_manual_guides_backup_날짜시간에 백업하고 다음만 교체/추가합니다.

- lib/data/guides.dart: 직접 선택 전용 데이터와 새 이미지 연결
- lib/ui/guide_page.dart: 해당 품목이 직접 선택 안내임을 표시, 기존 확대 수정 유지
- lib/ui/item_picker.dart: 기타 품목은 사진 분석으로 구분하지 않는다고 설명
- test/detection_test.dart, test/guide_assets_test.dart, test/widget_test.dart: 새 데이터/이미지/직접 찾기 검증
- assets/guides/film.png, assets/guides/mixed_packaging.png: 새 원본 이미지 2장

서버·best.pt·YOLO 클래스·추론 임계값·pubspec.yaml은 바꾸지 않습니다. 기존 assets/guides/ 디렉터리 등록을 사용하며 패키지를 추가하지 않습니다.

## 3. 검사와 S25 재설치

```powershell
cd C:\Users\haewo\recycling_app
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter run
```

새 이미지가 앱 번들에 들어가므로 hot reload만 하지 말고 새 버전을 S25에 설치해야 합니다. flutter run을 할 때 S25를 USB로 연결하고 USB 디버깅을 허용하세요. 기기가 여러 대면 flutter run -d 실제기기ID로 지정합니다.

설치 후 직접 안내 찾기는 USB·서버·인터넷 없이 사용할 수 있습니다. 사진 분석 기능은 기존처럼 PC 서버와 USB 연결이 필요합니다.

## 4. 확인

- 사진을 선택하지 않고 기타 → 비닐을 확인하면 비닐 이미지 표시.
- 품목 변경 → 기타 → 여러 재질이 섞인 포장으로 바꾸면 복합재질 이미지 표시.
- 이미지를 눌러 확대·닫기.
- 품목을 유리로 바꾸면 이전 이미지가 없어지고 준비 중 표시.
- 종이/플라스틱/캔의 기존 이미지도 유지.

## 자료와 한계

비닐 이미지의 기관·공공누리·날짜는 이미지 내 표기로 기록했습니다. 복합재질 이미지에는 한국소비자원 '재질별 분리배출' 참고 표기만 있어, 해당 자료의 원문 링크·날짜·이용 조건을 만들지 않았습니다. 두 자료의 원문 권리는 별도로 확인되지 않았습니다. 복합재질 원본 오른쪽 문장 일부가 잘려 보이며, 임의로 문장을 복원하거나 이미지를 편집하지 않았습니다. 수정본을 추후 보내면 같은 연결에 교체할 수 있습니다.

이미지 SHA256·PNG 디코딩·assets 등록·Dart/PowerShell 구문을 검사했습니다. 이번 버전 Flutter analyze/test와 실제 S25 동작은 SDK/기기 부재로 이 클라우드에서 실행하지 못했습니다. 테스트에서는 직접 안내 찾기 중 사진 분석 API 호출이 0회인지도 검사하도록 작성했습니다. 재학습은 하지 않았습니다.
